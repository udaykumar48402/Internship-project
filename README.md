💳 Credit Card Default Prediction

A machine learning project to predict whether a customer will default on a credit card using Logistic Regression.

📂 Dataset
2000 samples
Features: Income, Age, Loan, Loan to Income
Target: Default (0 = No, 1 = Yes)
⚙️ Model
Algorithm: Logistic Regression
Train-Test Split: 70:30
📊 Results
Accuracy: 95%
Precision (1): 0.83
Recall (1): 0.79
🚀 Tech Stack
Python
Pandas
Scikit-learn
